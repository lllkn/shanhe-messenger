# 公开源码验证记录

验证日期：2026-11-26（Asia/Taipei）。基础来源为原工程 0.1.2，公开版标记为 0.1.2-public。

## 环境与范围

- macOS / Apple Silicon，Godot 4.7.2.stable.official。
- Python 3 标准库；无第三方 Python 依赖。
- 测试对象为本仓库公开源码的临时副本，不使用完整素材包。
- 临时项目使用随机应用名称，API 环境变量被清空，默认服务端点替换为本地回环地址；测试后清理临时用户数据。
- 未调用真实模型服务，未读取作者原项目的密钥、存档或设置。

## 核心检查

| 检查组 | 结果 | 验证内容 |
| --- | --- | --- |
| Godot 无头编辑器导入 | 通过 | 公开脚本和场景可导入，无脚本解析错误 |
| 默认主菜单无头启动 | 通过 | 基础样式和系统字体回退，运行 30 帧后退出 |
| 大理离线规则 | 通过 | 六轮可操作、笔画不足不直接过关、离线完成通关 |
| HTTP 本地故障注入 | 通过 | 正常/慢响应、503 重试、401 不重复请求、现实时间超时、错误响应和手动恢复 |
| SSE 本地故障注入 | 通过 | UTF-8 逐字节分片、增量绘制、曲线库、503 重试、401、断流清稿和完整回退 |

五组全部通过；原有测试输出中共记录 61 项 PASS 断言，两个协议测试均报告 failures=0。检查入口同时把非零退出码、脚本错误、引擎 ERROR 和 FAIL 输出视为失败。

复现命令：

```sh
python3 scripts/audit_public.py
python3 scripts/check_core.py --godot /path/to/Godot
```
