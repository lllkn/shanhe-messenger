# 素材与发布边界

本仓库从当前主工程白名单复制后建立新的 Git 历史，未导入旧草稿、运行包或历史提交。

## 保留与排除

| 保留 | 排除 |
| --- | --- |
| GDScript、shader、文本场景、有效 UID | 图片、SVG、音视频、字体二进制 |
| 玩法、对白、站点与流程 JSON | GLB、GLTF、Blender 和模型制作源文件 |
| 系统字体文本配置、导出插件源码 | `.res`、`.pck`、导入缓存与碰撞二进制 |
| 技术文档、测试与本地 HTTP mock | 私人配置、存档、API 密钥、日志、截图 |
| 公共服务地址、空白配置模板 | 携带密钥的打包脚本及导出预设 |
| 纯文本发布检查工具 | 参赛材料、承诺书、身份信息、工作记录 |

素材路径字符串保留以展示接口，不代表对应文件随仓库发布。`assets/shared/` 只保留代码型资源及系统字体配置。`.gitignore` 屏蔽媒体、凭据、缓存、打包产物与私人目录；`scripts/audit_public.py` 进一步检查实际文件。

## 资源接口

| 原资源位置 | 用途 | 缺失影响 |
| --- | --- | --- |
| `game/assets/cities/<city>/` | 地图和碰撞资源 | 城市场景不能完成加载 |
| `game/assets/characters/` | 模型、元数据、立绘与照片 | 人物及对话画面不完整 |
| `game/assets/ui/` | 主界面、长卷、线索卡 | 基础界面可回退，部分模块仍缺图 |
| `game/assets/puzzles/` | 背景、题卡、人物表情 | 视觉不完整，不承诺完整可玩 |
| `game/assets/audio/` | 配乐 | 无配乐，缺失时静默跳过 |
| `game/assets/cinematics/` | 前情片和转场图 | 默认从主菜单开始 |
| `game/assets/shared/fonts/` | 原字体文件 | 改用系统中文字体 |

重新接入需同时核对 `data/`、代码路径、地图锚点、人物元数据与碰撞数据。仅补一张图片不能恢复完整城市或人物系统。

## 公开版代码差异

1. 使用独立应用名称和用户数据目录，默认入口改为 `Main.tscn`。
2. `UiKit` 缺图集时使用原生样式；通用图片入口允许空纹理，滑杆缺图时采用默认图标。
3. 字体资源改为系统字体，不分发字体二进制。
4. 缺配乐时跳过；开场删除强制影片依赖，转场图片采用可选加载。
5. API 密钥仅从环境变量或 `user://llm.cfg` 读取，不从工程内读取。
6. 工具中的作者电脑绝对路径改为 `user://technical-previews/`；流式测试输出改为 `user://test-output/`。
7. 大理小游戏对图片采用可选加载，便于无素材执行核心测试。
8. 新增文件审计和核心测试入口；保留完整资源测试并明确其前提。

这些差异只作用于公开副本，不修改原工程。没有用内嵌媒体或替代图片绕过排除要求。

## 继续贡献

提交前运行 `python3 scripts/audit_public.py`，并检查 `git diff --cached`。密钥模板保持空白，截图与原始日志不进入公开提交。新增媒体目前会被忽略；改变发布边界前须获得作者授权。
