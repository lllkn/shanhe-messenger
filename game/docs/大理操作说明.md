# 大理 · 老纹样访查

使用 Godot 4.7.2 打开 `game/project.godot`。正式旅程从长卷进入已解锁的大理；单独试玩可打开 `tools/DaliPlay.tscn` 按 F6，使用 `dali-play.cfg` 专用新档，每次重新运行从开场开始，不覆盖正式玩家存档。

## 地图与操作

WASD移动，Shift跑，空格跳，E交谈，Esc暂停。鼠标直接转动斜俯视镜头，滚轮缩放，R恢复大理默认镜头。Tab显示/收起光标，显示光标时可以点访查清单和小地图切换目标。金色路标和小地图来自同一条实际可行走路线；它们只引路，不自动移动角色。

镜头以当前角度、距离固定跟随人物：鼠标直接转向，滚轮设定7—16米距离，松手后保持，只有R会恢复默认视角。已关闭镜头碰撞、自动绕墙、自动缩放和自动回正；只平滑地面台阶的高度抖动。建筑完整呈现，人物实体碰撞保留。镜头被建筑遮挡或进入模型时，需手动转动、缩放查看。

人物头顶显示姓名，到交谈范围且视线无遮挡时，人物旁显示E提示。前置条件未齐时婆婆提示先完成走访。进入对话、暂停或窗口失焦会释放鼠标；结束对话后先松开空格再跳。

## 大理主线

才村码头开场旁白 → 乳扇摊主、扎染店姑娘、民居巷阿婆（三处顺序自由） → 周城扎染坊婆婆 → 自动进入原版你画我猜 → 自动回原地点、接婆婆收尾 → 扎染纹样碎片 → 解锁普洱。

对话有旁白姓名卡，正文36字号居中。点击或空格先补全当前文字，再继续下一句。完整读完才保存该段完成标记，中途结束不计线索。重复访谈可读短对白，不重复计数。地图仅保留三处访谈与周城扎染坊主线目标；照壁巷、三塔远眺不再提供风物标记和观察交互。

婆婆核心对话保留已审核前段，后段采用七句精简稿。民居巷阿婆采用“这个得让她自己看。我跟她来往这么多年，也认不得。”。

## 原版小游戏与奖励

前三轮婆婆画，玩家四选一；后三轮玩家照纹样卡画，婆婆猜。累计认对至少五次过关，不够则沿用补充练习。未配置密钥或断网可走原有本地模式；联网设置见《LLM接入说明》。本轮保留题池、笔法、判定和双三轮规则。

从城市主线进入，通关只保存小游戏通过状态，自动回地图接收尾，收尾前不发碎片、不解锁下一站。收尾中断后再次进入大理会自动恢复收尾，不需要重玩小游戏。游戏中途退出则回到原位置和完整镜头，可再找婆婆开始。独立F6小游戏的内存试玩和旧直接入口保留原结算页。

已有大理碎片的旧档直接显示已完成，可重访人物，不要求重新开场或重玩。地图女主和四位NPC已接入大理独立GLB：女主沿用低马尾、黑框眼镜与雾蓝月白裙装，民居巷阿婆和扎染婆婆是不同人物。坊内仍使用已有背景，没有新增可步行3D室内。


## 人物与照片

交谈左侧是当前NPC，右侧是已有女主剪影；说话时调整明暗。收尾中姑娘与婆婆轮流发言，左侧跟随她们切换；主角和旁白发言时保留上一位NPC。开场没有虚构NPC。

开场A02—A03展示古锦照片；摊主B02—B05、姑娘C02—C05、阿婆D04—D05、婆婆F04—F07展示对应访查照片。照片以清晰完整的原图展示，隐藏亮度、放大和确认按钮，可直接继续对话。收尾H15—H18同样只展示照片。再次和完成后的短对白不加载手机。

完整结束首次交流才记走访，操作过照片后退出也不算完成。再次交谈从首次全文重新开始；完成过的访谈使用已确定的两句简短回应，完成整城后使用原来的完成回应，婆婆再访仍保留已确定三句。再访不重复计数或发奖。

素材图册：`素材/modules/dali/characters-v01/index.html`（项目根目录）。人物专项测试：`tests/DaliCharactersTest.tscn`；主线测试仍为`tests/DaliChainTest.tscn`。新素材属于本轮候选，尚未登记为用户验收版本。

地图底部用文字提示当前鼠标模式：按 **Tab** 显示鼠标，可点击任务、小地图和行囊；再按 **Tab** 收起鼠标并恢复转视角。Esc 用于暂停；对话、领奖和暂停期间会自动释放鼠标。
