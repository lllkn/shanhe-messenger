# 香格里拉 · 古锦访查

Godot 4.7.2 打开本目录 project.godot。正常旅程从丽江完成后进入；单站试玩打开 `tools/XianggelilaPlay.tscn`，按 F6。试玩使用独立档，不更改正式旅程存档。

月光广场开场 → 布料店老板、广场游客、民居巷年轻人（顺序自由）→ 村尾染坊丹增 → 补锦纹、染一缸 → 丹增核对记录、儿子帮忙收缸 → 五色锦纹碎片 → 留城或去大理。

WASD 移动，Shift 跑，空格跳；直接移动鼠标转视角，滚轮缩放，R 恢复斜俯视。Tab 显示光标，可点击走访清单、小地图选择引导目标，也可打开行囊、返回长卷；Tab 再次进入转视角模式。Esc 暂停。到人物旁按 E 交谈。金色方向箭头沿真实可走路径引路，不自动移动。

对话正文36字号，旁白有姓名卡；点击或空格补全文字，再次点击或空格继续，Enter也可继续。完整访谈才记录线索；中断后可重新交谈。已走访清单的悬停提示可查看线索。年轻人交谈后显示为丹增的儿子。

核心对话结束自动进入小游戏。开始页点击大号“开始补锦”按钮才进入操作。第一关先选1—5色，再点击同号区块，可拖动连涂、Ctrl+Z撤销。当前色号、色名与剩余区块数常驻右侧；已选色片标注“已选”，对应未填区块描金加粗。第二关在同一染料卡上停留超过1秒，丹增才解释对应颜色；快速划过不切换，移出1秒后恢复下料提示。依青、赤、黄、白、黑拖入对应材料；等火候后按住水面绕两圈，四秒内搅匀。白色步骤称“练白”；手记是游戏提示，不是现实染色配方。

退出小游戏回原位置与视角，不记通关；再次找丹增可重试。两关完成先停留在胜利结算页，显示38块补锦和5色成色结果；点击“确认完成 · 返回染坊”后才回城播放收尾，收尾中断保留过关成果。完整收尾后才显示手记、发放原碎片并解锁大理。进度自动保存，旧已完成档不强制重新走访。

当前玩家与地图人物沿用占位胶囊；核心剧情采用已有染坊院景，未新增可步行室内。两座溪桥可通行，其他溪水由实体安全阻挡限制横穿。未导出独立可执行包。

地图底部用文字提示当前鼠标模式：按 **Tab** 显示鼠标，可点击任务、小地图和行囊；再按 **Tab** 收起鼠标并恢复转视角。Esc 用于暂停；对话、领奖和暂停期间会自动释放鼠标。
