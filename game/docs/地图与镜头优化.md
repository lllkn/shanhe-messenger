# 3D地图与普洱镜头优化 · 2026-10-15

现有四城3D地图已核验接入；不是平面背景图。保留模型、材质、原地图文件与已修正的大理版本。

## 试玩

主工程：打开 `game/project.godot`，在Godot打开 `tools/PuerPlay.tscn`，按F6。已有游戏窗口须停止后重启才能载入脚本。使用独立 `puer-play.cfg`，不影响正式存档。

WASD移动、Shift跑、空格跳、鼠标转视角、滚轮缩放、R复位、Tab释放鼠标、E交互。

## 修复

- 普洱B_04矮楼的cream、blue等墙体材质合批原先未进入镜头碰撞；补齐后重新烘焙18组建筑形状。
- 镜头同时检测人物头部、躯干、脚下与身体两侧；球体扫掠为近裁剪面留出空间。
- 收近即时生效，离开建筑后平滑恢复；沿当前轨道重新计算，避免世界坐标插值穿过墙角。
- 屋檐附近优先降低实际俯仰角，极窄巷口再向附近开阔方向避让。用户选择的视角、缩放距离与移动方向仍保留；R照常复位。

源文件：`scenes/cities/FollowCameraSafety.gd`、`scenes/cities/PuerCity.gd`的镜头覆盖函数、`tools/BakeCityCollision.gd`、`assets/cities/puer/camera_collision.res`。

只重建普洱碰撞：

```sh
BAKE_CITY=puer /Applications/Godot.app/Contents/MacOS/Godot --headless --path game --script res://tools/BakeCityCollision.gd
```

## 实测

Godot 4.7.2 / macOS / Apple M5，窗口实测使用Metal Forward+。

- 四城GLB与出生/剧情锚点均加载成功：丽江97、香格里拉429、大理90、普洱42个网格资源。
- 普洱84个道路采样点 × 12个方向 × 3个俯仰角 × 3档距离 = 9,072组。采用独立从GLB生成的建筑碰撞层验证，而不是仅用新烘焙的碰撞数据自证。
- 原版镜头：39组人物视线被遮挡，21组镜头球体与建筑重叠，288组镜头距离小于1.5米。
- 修复镜头：上述三类均为0，最短实际距离约2.41米。
- 连续改变位置、方向、缩放且不重置相机：视线遮挡0、球体重叠0。
- 独立普洱候选的90项链路回归通过，包括真实键盘步行、鼠标/Tab/R输入、台阶、墙体、边界、对话、中断、返回、领奖与旧存档。
- 主工程在人物和线索界面更新接入后再次运行地图/镜头测试，9,072组与连续运动检查均通过，未出现脚本或资源加载错误。

这是道路采样及既有链路覆盖，不表示任意跳跃位置、所有屋檐内部与所有自由镜头组合都已经穷举。

## 2026-10-19 显示与视角设置

工程使用 `canvas_items` + `keep`，保持 1280×720 的16:9比例，全屏遇到其他比例时留边。“游戏设置 → 地图视角速度”可在25%—200%之间调节，默认50%，恢复推荐按钮回到50%；立即生效且重新启动后保留。五站及基础城市使用 `InputEventMouseMotion.screen_relative`，每个屏幕像素按 `0.003 * camera_sensitivity` 弧度转动，横纵轴共用速度，不受内容缩放影响。Tab光标、暂停、对话与失焦状态继续禁止转向。

回归：`tests/DisplayControlsTest.tscn`，覆盖旧设置迁移、保存重载、调节范围、设置控件、4种窗口比例、实际全屏切换和五站输入。测试使用独立存档与设置文件。
