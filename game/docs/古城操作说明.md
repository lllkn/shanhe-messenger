# 古城 · 回来的人

2026-10-15。沿用原古城地图（丽江几何），复用四城的移动、镜头、金色引路、小地图、E提示、姓名卡和36字号对话。

主线在普洱收尾并收好手记后，点击「去下一个地方」进入；也可在长卷选择已解锁的古城集场。首次进入先交代：普洱寻访后，女主回台整理纪录片；播出后，馆里联系人介绍她前往古城织坊，请木老爷核对沿途记录。

地图只有木老爷一个任务点，没有额外访谈或线索门槛。按金色箭头走到织坊，靠近木老爷按E。正常读完后，小木因看到了电视台纪录片回来，向爷爷提出接着学。最后一句对白为「坐吧，咱们慢慢来。」小木坐下，女主举起相机，实时镜头退开、淡出进入片尾。没有学习操作、拼锦、分档结局或额外碎片。

- WASD移动；Shift跑；空格跳；鼠标直接转视角；滚轮缩放；R复位；Tab切换光标；Esc暂停。
- 对话点击或空格/Enter补全文字，再次操作继续；中断不标记整段完成，再找木老爷可重新阅读。
- 行囊返回保留城市位置及视角。片尾可重温终章、返回长卷、返回主页面；重温不重复结算。
- 直接试玩：打开 `tools/GuchengPlay.tscn` 按F6。使用 `user://gucheng-play.cfg`，不修改正式存档；每次从普洱完成后的状态开始。

地图及最后拍照镜头继续复用四城v02模型与轻量动作：女主沿用丽江模型并适配古城衣色，木老爷复用老年模型并移除东巴法冠与经卡，小木复用香格里拉青年模型并适配外套颜色。对话改为与前四城画风一致的二维卡通立绘，三位人物分别保存在`assets/characters/gucheng/`；女主沿用已确认的古城服装、低马尾和黑框眼镜。人物随说话高亮，小木到进门那句才出现，不新增手机操作。结尾仍是原3D退镜，不是预录影片。
