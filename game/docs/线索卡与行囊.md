# 线索卡与行囊

四城共 12 张访谈线索，按城市与手艺分类：丽江 / 东巴文字、香格里拉 / 手工染色、大理 / 扎染纹样、普洱 / 贝叶文字。

- 完整读完首次访谈后，弹出手绘线索卡；点击「收好线索」或 Esc 合上。
- 地图按 Tab 显示鼠标，点击左上角已完成的人物卡／任务，打开对应线索。未完成任务仍负责引路；小地图继续负责引路。
- 行囊默认打开线索页，可切换全部城市或单城分类；未获得的卡不显示标题和正文。
- 「信物手记」单独保留原有四城最终奖励和手记重读。
- 卡片打开时停止移动和视角输入；关闭恢复之前的鼠标偏好。失焦仍释放鼠标。
- 普洱第三处访谈结束后先收卡，合上后播放原有走访总结。

`ClueBook.gd` 从原城市访谈数据读取身份，标题/摘要集中在同一目录类中；只查询原存档 `clue/城市/人物`，无需迁移，地图、行囊、任务入口不另存进度。
`ClueCard.gd` 统一制作详情卡和行囊缩略卡，左上角任务栏保留原有文字列表；`CityClues.gd` 管理地图弹层与继续剧情。

手绘纸卡是内置 image_gen 生成素材，人物沿用原工程立绘。原图与最终提示词见 `assets/ui/clues/`；文字由游戏控件排版，避免生图文字错误。

使用 Godot 4.7.2 打开 `project.godot`，F5 正常游玩。专项回归 `tests/ClueCardsTest.tscn` 使用独立存档，不覆盖正式玩家进度；设置 `CLUE_EVIDENCE` 可输出原生窗口截图。也可在 Godot 中运行单城 `tools/*Play.tscn` 做新旅程试玩。

行囊缩略卡与详情共用 940×558 的卡面坐标，容器按宽度计算相同比例的高度，底图、立绘、标题和正文一起等比缩放。专项布局回归：`tests/ClueInventoryLayoutTest.tscn`，覆盖1280×720、1600×900和1280×900窗口、12张卡与点击/滚动。
