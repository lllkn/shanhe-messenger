# 普洱操作说明

鼠标直接移动转视角，滚轮缩放，R恢复默认斜俯视。WASD移动，Shift跑，空格跳。按Tab显示光标，点击左侧走访清单或右上小地图选择引路目标；再次按Tab恢复转视角。Esc暂停。

跟随金色方向箭头前往人物，进入可交谈范围后，人物旁出现「E 对话」。按E交谈；旁白和人物都有姓名卡，正文使用36字号，在正文区域居中。点击或按空格、Enter补全本句，再按一次继续。右上「结束交谈」可中断，未完成的交谈不记进度。

路线：寨口开场 → 竹楼女主人、茶农、小沙弥（三处顺序自由） → 奘房岩香 → 自动进入贝叶归册 → 自动播放8句收尾 → 获得贝叶誓约碎片、解锁古城集场。

小游戏先挑出六张互助约定，点击两端金点打孔，再从上到下拖动排序。点击「检查顺序」，岩香逐句念读。顺序不通的叶子落下，可拖回；选错或排序连续失败会得到提示。中途退出不发碎片，回到原地点和视角；再次找岩香可重新开始。两关已通过时，收尾中断后会保留整理成果，回来只需继续收尾。

通关后的误导领奖文字和重复誓约页已从主线移除。只有8句收尾读完才发原有碎片；已经完成普洱的旧档不要求重新走访，也不重复领奖。

直接试玩：Godot打开本工程 `tools/PuerPlay.tscn`，按F6，或运行：

```sh
/Applications/Godot.app/Contents/MacOS/Godot --path game res://tools/PuerPlay.tscn
```

该入口使用独立普洱试玩档，不改正式玩家存档。已有运行窗口需先停止并重新运行才能载入最新修改。主线仍由长卷进入普洱，沿用原有解锁条件。

茶山观景台和贝叶棕林为可探索风景，不增加必做任务。地图没有河道与桥；观景台由台阶登上，外围茶山和建筑内部没有新增探索区域。地图女主采用已定普洱茶绿裤装，四位NPC采用对应独立Q版3D模型。对话左侧为当前NPC，右侧为原女主剪影；收尾中的小沙弥发言使用本城小沙弥。已读完的街头访谈再聊为一句短回应，岩香通关再访为两句；中断初次交谈不记完成。

古锦照片沿用同一块馆藏古锦，手机复用原设备。照片出现时直接展示清晰完整的原图，隐藏亮度、放大和确认按钮；岩香看文字段落时也可直接继续对话。退出后再谈从首句重新开始。小沙弥访谈与各次简短再访只保留人物舞台。

人物候选素材展示：项目 `素材/modules/puer/characters-v01/index.html`。冻结源码、独立验证与测试记录：`drafts/puer-characters-20261011/`；这些技术通过不表示用户已验收新美术。

地图底部用文字提示当前鼠标模式：按 **Tab** 显示鼠标，可点击任务、小地图和行囊；再按 **Tab** 收起鼠标并恢复转视角。Esc 用于暂停；对话、领奖和暂停期间会自动释放鼠标。
