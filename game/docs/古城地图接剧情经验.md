进入任何古城入口都用同一个arrival交代普洱完成后制作、播出纪录片及馆里推荐木老爷的原因。过渡完整读完才记`flow/gucheng/arrival`；visit完整读完才记`flow/gucheng/visit`，并补记workshop。收尾镜头中禁止移动与交谈，退镜3秒、淡出1.8秒，随后保存`flow/gucheng/ending`并完成本站。中断只保留已读完整段落。

如果读完visit后在镜头中关游戏，重进可恢复收尾。早期占位可能把无碎片的古城直接标为完成；如果缺少新visit标记，仅清除古城完成状态，保留四城碎片与其他进度，让新终章实际播放。新完成档再次进城不自动重播，片尾「重温终章」显式传入replay_ending参数。
