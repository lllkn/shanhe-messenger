# 大理“你画我猜”LLM 接入

API 为可选功能。仓库只含接入代码、公共服务地址与空白模板，不含作者密钥、用户数据或在线测试日志。

## 配置自己的密钥

`PuzzlePattern.gd` 按以下顺序读取非空配置：

1. 环境变量 `BIGMODEL_API_KEY`、`ZHIPU_API_KEY`、`LLM_API_KEY`。
2. Godot 用户数据目录中的 `user://llm.cfg`。

在 Godot 选择“项目 → 打开用户数据文件夹”，把仓库根目录 `examples/llm.cfg.example` 的内容复制到该目录的 `llm.cfg`，仅在本机填写：

```ini
[llm]
api_key=""
```

公开版应用名与原工程不同，使用独立用户数据目录。不要把密钥存入 `game/`、提交到 GitHub 或随客户端导出。原私有打包脚本和工程内凭据读取路径已排除。

服务地址、模型名称与参数在 `game/data/puzzles.json` 的 `dali.llm` 中维护，沿用原工程配置，不保证当前服务状态或费用。需要自行核实账户权限。

## 互动与降级

婆婆作画通过 SSE 接收增量命令，由 `PatternInk.gd` 和 `PatternBrushLibrary.gd` 转成逐笔动画；玩家画布可通过视觉请求交给模型识别。在线模式会向所配置的外部服务发送提示词，识图时还会发送画布。没有密钥、鉴权失败、超时、限流或响应异常时，代码按错误类型重试或回退本地逻辑。

“已就绪”只表示读取了密钥；“在线 · 已收到回应”才表示收到响应。连接成功不能保证识别准确。

## 不调用真实服务的测试

从仓库根目录执行：

```sh
python3 scripts/check_core.py --godot /path/to/Godot
```

入口使用临时用户目录、清空的 API 环境变量和本地 HTTP mock，覆盖文本错误响应、SSE 分片、重试、鉴权失败与断流回退。公开版没有执行真实在线调用。

原 `game/tests/` 仍有带 `--live`、`--llm-live` 的入口，它们会调用真实服务，不属于默认离线验证。
