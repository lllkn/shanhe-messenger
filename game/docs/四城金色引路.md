# 四城金色引路

丽江、香格里拉、大理和普洱共用 `core/CityRouteGuide.gd`。四城的箭头颜色、深色细边、尺寸、间距、更新和到达规则一致；各城仍按自己的真实地形、道路和碰撞寻路。

按 Tab 显示光标，点击任务清单或小地图选目标。沿箭头行走，小地图收起走过的部分；底栏显示沿路线的剩余距离。到达目标后收起箭头，靠近人物按 E 对话。

## 稳定性规则

- 选定目标时规划一次，保存整条路线和箭头的世界坐标。沿路线前进、原路返回、站立和普通跳跃都不会重新排整条箭头。
- 箭头每隔 1.3 米一个，走过的部分按进度收起；原路返回时恢复原位置的路标。只在需要收起或恢复箭头时重建显示网格。
- 偏离路线超过 1.8 米，持续至少 0.75 秒后重新规划；短暂侧移不会频繁换路线。重规划间隔至少 1 秒。
- 到达目标后，离开交谈半径另加 0.6 米才恢复引路，减少边缘闪烁。对话、领奖期间隐藏引路；城市完成后清除世界和小地图路线。
- 找不到路线时清除旧线并提示移回街道；玩家站立时不会反复寻路，回到可行走的位置后再尝试。
- 箭头被附近的低矮铺面或路面装饰盖住时，补绘被遮挡的部分。修正限制在高度差0.65米、平面距离0.9米以内的平缓表面；竖直墙面、屋顶和高物体仍遮挡路标。普通无遮挡路面继续使用原来的金色材质。

世界箭头、小地图路线和距离提示都来自同一条保存的路径。距离采用水平路程，保留地形高度用于贴地显示。

## 开发与验证

`NarrativeCity.gd` 与 `CityStory.gd` 只负责把目标、进度和人物状态交给共用组件。后续调箭头或稳定性只修改一个组件。`CityWalkGuide` 继续负责真实可走格点采样，普洱的道路中心线加权继续保留。

引路专项测试：运行 `tests/CityGuideTest.tscn`，检查四城全部目标、原地晃动、跳跃、前进和返回、路标顶点固定、60 fps 下偏离计时、重复选目标、到达边缘、无路径恢复、对话和完成状态。现有各城 ChainTest 覆盖真实 WASD 实走、桥梁、碰撞、对话与任务链。

遮挡专项测试：以实际窗口运行 `tests/CityGuideOcclusionTest.tscn`。像素检查包括无遮挡、抬高铺面、斜铺面、高墙、高盖板及低矮竖直墙面，并对比修正前后的箭头可见像素。不能用headless结果代替这项渲染检查。

直接试玩：在 Godot 编辑器分别打开 `tools/LijiangPlay.tscn`、`tools/XianggelilaPlay.tscn`、`tools/DaliPlay.tscn`、`tools/PuerPlay.tscn`，按 F6。四个入口使用各自独立的试玩存档。
