# 城市探索完成引导

丽江、香格里拉、大理、普洱的完成页统一显示以下三个按钮，顺序和样式共用 `ui/CityCompletionChoices.gd`：

1. **继续探索**：关闭完成页，留在当前地点，恢复移动与原来的鼠标模式；要求先松开空格再跳跃。
2. **去下一个地方**：按 `data/stations.json` 的顺序直接进入下一站地图。丽江 → 香格里拉 → 大理 → 普洱 → 古城集场。
3. **返回旅途长卷**：打开旅程总览。

四城均在收尾领奖后先显示双页手记，收好手记后显示这三个选项。手记共用 `ui/JourneyJournal.gd`，各城内容在 `data/journals.json`；`DyeKnowledge.gd` 保留染坊原调用入口。导航不发放碎片，也不改变剧情完成条件。

古道信物页统一为纸页手记卡片。已收集卡片可以打开同一份双页手记重读，合上返回信物页；未收集卡片显示获取提示。手记只负责展示，重读不写存档。

使用 Godot 4.7.2 打开 `project.godot`，按 F5 试玩主线；也可通过各城 `tools/*Play.tscn` 独立试玩。古城集场采用独立片尾：线性对话结束后退镜、淡出，可重温终章、返回长卷或主页面；没有额外领奖或下一站。四座城市继续使用上述统一完成页。

专项回归 `tests/CityCompletionTest.tscn` 使用独立测试档，验证四城收尾手记及布局、按钮顺序、移动及鼠标恢复、下一站、长卷返回、重复进入，以及信物卡片解锁和重读不改存档。无窗口执行：

```sh
godot --headless --path <game目录> res://tests/CityCompletionTest.tscn
```

用窗口运行并设置 `CITY_COMPLETION_OUTPUT` 为已有截图目录，可以检查四城完成页的完整布局及鼠标恢复。
