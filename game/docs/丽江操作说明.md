# 丽江操作说明

鼠标直接移动即可转视角，无需按住鼠标按钮。滚轮缩放，R恢复默认斜俯视。

WASD移动，Shift跑步，空格跳跃。跟随金色方向箭头寻找人物；接近后，人物旁会显示「E 对话」，按E开始交谈。

对话可以点击或按空格继续：文字正在出现时补全本句，文字完整后继续下一句。Enter也可继续；出现分支时选择选项。右上「结束交谈」可中断，之后再次找人物重来。

街头三位NPC首次完整交谈后，再次交谈只说一句简短回应；未读完就退出仍会从初次对话开始。阿东巴在任务完成后也只作简短招呼。

旁白和人物对话都会显示姓名卡。阿东巴核心对话结束后直接进入小游戏，不需要回地图再按E；中途退出小游戏仍回到原地点，可再次找阿东巴继续。

按Tab显示光标，点击左侧任务或右上小地图选择引路目标，也可打开行囊或返回长卷。再按Tab回到鼠标转视角。对话和暂停时会自动显示光标。

Esc暂停，在暂停菜单也能查看操作提示。

丽江路线：水车旁开场 → 银饰大姐、小学生、客栈老板（顺序自由） → 东巴院阿东巴 → 字卡辨认与马帮残页归序 → 收尾核对 → 获得碎片，解锁香格里拉。

直接试玩：在Godot打开 `tools/LijiangPlay.tscn`，按F6。已有运行窗口需要先停止、重新运行才能载入修改；该入口使用独立试玩档。

地图底部用文字提示当前鼠标模式：按 **Tab** 显示鼠标，可点击任务、小地图和行囊；再按 **Tab** 收起鼠标并恢复转视角。Esc 用于暂停；对话、领奖和暂停期间会自动释放鼠标。

手机照片：阿东巴要求调亮、放大时，必须把亮度调到70%以上并点击“放大纹样”，才能点击“让阿东巴看照片”。任一条件未满足都会拦截确认和继续。确认后调整栏收起，只显示清晰完整照片，点击正文或空格继续下一句。
