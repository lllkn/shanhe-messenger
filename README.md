# 山河信使 · 技术分享源码

《山河信使》是一款以茶马古道寻访为背景的 Godot 叙事探索与文化解谜项目。玩家以纪录片编导的身份，沿丽江、香格里拉、大理、普洱与古城展开寻访，通过对话、线索收集和小游戏推进旅程。

本仓库整理自项目 **0.1.2**，用于展示游戏工程组织、配置驱动叙事、城市模块复用，以及大模型互动的实现方式。**这里是移除私人配置和媒体素材的源码分享版，不是比赛成品或完整游戏资源包。**

## 适合用来研究什么

- **配置驱动叙事**：JSON 维护站点、对话、剧情标记、手记与碎片，脚本负责执行和展示。
- **城市模块复用**：共用地图、人物交互、引路、镜头与剧情框架，城市差异通过配置与子类表达。
- **小游戏集成**：字卡连接、五色染制、你画我猜、贝叶经归册，通过统一生命周期与奖励接口接入主线。
- **可选 LLM 互动**：大理“你画我猜”包含 HTTP 请求、SSE 增量解析、笔法库、重试与离线降级。模型负责识别与表达，题库与规则保留在本地。
- **进度与回归测试**：全局状态、自动存档、幂等奖励、场景路由与本地故障注入。

古城当前主线采用对话终章；仓库仍保留历史拼锦小游戏及相关配置，不代表它会在当前主线触发。

## 打开工程

使用与原工程一致的 **Godot 4.7.2**。Python 辅助脚本使用 Python 3.9+ 标准库，不需要 pip 安装依赖。

1. 克隆仓库，在 Godot 项目管理器中导入 `game/project.godot`。
2. 等待首次导入完成，按 F5 打开基础主菜单。公开版使用独立用户数据目录，避免覆盖原项目的存档与 API 配置。
3. 阅读 [架构与代码阅读路线](docs/ARCHITECTURE.md)，或运行下方核心离线测试。

**未附带：**图片（含 SVG）、字体文件、音视频、GLB/Blender 模型、碰撞二进制资源、截图、参赛材料、个人存档、私有配置、历史打包产物和旧 Git 历史。

公开版提供基础界面与系统字体回退，开场不再强制加载影片。**城市地图和依赖美术的完整玩法需要自行补齐有权使用的资源，不能直接复现成品画面或完整通关流程。**部分原场景仍会提示缺少素材；相关测试不属于无素材核心测试范围。未额外生成或上传占位图片。

资源对应关系及公开版差异见 [素材与发布边界](docs/ASSETS_AND_PRIVACY.md)。

## 核心离线验证

在仓库根目录执行：

```sh
python3 scripts/audit_public.py
python3 scripts/check_core.py --godot /path/to/Godot
```

macOS 可执行文件通常在 Godot 应用包的 `Contents/MacOS/Godot` 下。测试入口隔离用户数据、清空 API 环境变量，并使用本地 HTTP mock，不调用真实模型。实际结果和覆盖边界见 [验证记录](docs/VALIDATION.md)。

`game/tests/` 还保留依赖地图、美术或图形渲染的原测试，不能把核心测试通过等同于它们全部通过。

## API 配置可选

仓库不提供 API 密钥，也不要求先配置 API 才能读源码或运行核心测试。无密钥时，大理的模型交互会进入本地降级流程。

需要研究真实模型交互时，参照 [LLM 接入说明](game/docs/LLM接入说明.md)，自行配置环境变量或 Godot 的 `user://llm.cfg`。空白模板见 [examples/llm.cfg.example](examples/llm.cfg.example)。**不要把实际密钥放进仓库或客户端安装包。**

在线模式会向所配置服务发送提示词；视觉猜画还会发送玩家画布。请求代码在 `game/scenes/puzzles/PuzzlePattern.gd` 与 `game/puzzles/PatternSseStream.gd`。服务地址和模型名称沿用原工程，不代表当前服务可用性、价格或识别准确性的保证。
